## Overview
This project solves delivery routing problems using multiple algorithms like Greedy, Dynamic Programming, Graph Algorithms, and TSP.

---

## Algorithms
- Recurrence (cost calculation)  
- Greedy (parcel selection)  
- Dynamic Programming (time constraints)  
- Dijkstra & MST (shortest path)  
- TSP (optimal route)  

---

## Tech Used
- Python  
- Jupyter Notebook  
- matplotlib  
- networkx  

---

## Results
- Greedy is fast but not always optimal  
- DP improves constraint handling  
- TSP gives best route but slow for large inputs
